# Guide: Blatt 1, Aufgabe 5c, FTP Script

## Was macht das Script?

Das Script erstellt bei jeder Ausführung die aktuelle Unixzeit und lädt sie per FTP auf den Server hoch.

Die Unixzeit ist eine einzelne Zahl, z.B.:

```text
1771234567
```

Diese Zahl bedeutet: Sekunden seit dem 01.01.1970.

Die Datei auf dem FTP-Server darf nur diese eine Zahl enthalten. Keine Erklärungen, keine feste Zeit, keine zusätzlichen Inhalte.

---

## Vollständiges Script

Pfad:

```text
/home/secpgast/Abgaben/5/ftp
```

Inhalt:

```bash
#!/bin/bash

HOST="10.153.210.254"
USER="secpftp"
PASS="Shaexi2s"
REMOTE_FILE="gruppe09.secp.lab.nm.ifi.lmu.de"

date +%s | curl -sS -T - --user "$USER:$PASS" "ftp://$HOST/$REMOTE_FILE" >/dev/null 2>&1
```

---

## Was gibt das Script aus?

Normalerweise gibt das Script nichts im Terminal aus. Das ist richtig.

Der Erfolg wird geprüft mit:

```bash
echo $?
```

Wenn danach steht:

```text
0
```

dann war das Script erfolgreich.

Wenn danach steht:

```text
127
```

dann wurde ein Befehl nicht gefunden, z.B. `ftp` oder `curl`.

---

## Erklärung jeder Zeile

### Shebang

```bash
#!/bin/bash
```

Das sagt Linux: Dieses Script soll mit Bash ausgeführt werden.

---

### FTP-Server

```bash
HOST="10.153.210.254"
```

Das ist die IP-Adresse des FTP-Servers. In diesem Blatt ist das der `secserver`.

---

### Benutzername und Passwort

```bash
USER="secpftp"
PASS="Shaexi2s"
```

Diese Daten wurden vorher mit `tcpdump` aus dem FTP-Verkehr ausgelesen.

Der Mitschnitt zeigte:

```text
USER secpftp
PASS Shaexi2s
```

Das funktioniert, weil FTP Benutzername und Passwort unverschlüsselt überträgt.

---

### Dateiname auf dem Server

```bash
REMOTE_FILE="gruppe09.secp.lab.nm.ifi.lmu.de"
```

Die Aufgabe verlangt, dass die Datei nach dem Domainnamen der Gruppe benannt wird.

Für Gruppe 09 ist das:

```text
gruppe09.secp.lab.nm.ifi.lmu.de
```

---

### Aktuelle Unixzeit erzeugen

```bash
date +%s
```

Das gibt die aktuelle Zeit als Unixzeit aus.

Beispiel:

```text
1771234567
```

Diese Zahl ist der Inhalt, der hochgeladen werden soll.

---

### Pipe

```bash
|
```

Die Pipe gibt die Ausgabe des linken Befehls an den rechten Befehl weiter.

Hier bedeutet das:

```text
date +%s erzeugt die Zeit
curl bekommt diese Zeit als Eingabe
```

---

### curl Upload

```bash
curl -sS -T - --user "$USER:$PASS" "ftp://$HOST/$REMOTE_FILE"
```

Bedeutung:

```text
curl                  = Tool für Netzwerkübertragungen
-sS                   = leise ausführen, Fehler trotzdem erkennen
-T -                  = Upload, Daten kommen von der Standardeingabe
--user "$USER:$PASS"  = FTP Login mit Benutzername und Passwort
ftp://...             = Ziel auf dem FTP-Server
```

Mit den Variablen wird daraus sinngemäß:

```text
Lade die Ausgabe von date +%s auf ftp://10.153.210.254/gruppe09.secp.lab.nm.ifi.lmu.de hoch.
```

---

### Ausgabe unterdrücken

```bash
>/dev/null 2>&1
```

Bedeutung:

```text
>/dev/null = normale Ausgabe wird verworfen
2>&1       = Fehlerausgabe wird ebenfalls verworfen
```

Warum machen wir das?

Das Testsystem soll keinen störenden Text vom Script bekommen. Das Script soll einfach sauber laufen und mit Exit-Code `0` enden.

---

## Script ausführbar machen

Nach dem Speichern:

```bash
chmod +x /home/secpgast/Abgaben/5/ftp
```

Bedeutung:

```text
chmod = Rechte ändern
+x    = ausführbar machen
```

Ohne diesen Schritt kann das Testsystem das Script eventuell nicht starten.

---

## Script testen

```bash
/home/secpgast/Abgaben/5/ftp
echo $?
```

Erwartet:

```text
0
```

Das bedeutet: Das Script wurde erfolgreich ausgeführt.

---

## Warum kam vorher Return Value 127?

`127` bedeutet meistens:

```text
command not found
```

In der alten Version wurde wahrscheinlich `ftp` benutzt. Wenn `ftp` auf dem System nicht installiert ist, bricht das Script mit `127` ab.

Die Lösung war, `curl` zu verwenden.

---

## Was haben wir insgesamt gemacht?

1. FTP-Verkehr auf `ens8` mitgeschnitten.
2. Benutzername und Passwort im Klartext gefunden.
3. Script unter `/home/secpgast/Abgaben/5/ftp` erstellt.
4. Script mit `chmod +x` ausführbar gemacht.
5. Script erzeugt mit `date +%s` die aktuelle Unixzeit.
6. Script lädt diese Zahl per FTP auf den Server hoch.
7. Script gibt nichts aus und beendet sich erfolgreich.
8. `echo $?` liefert `0`.

Ja, technisch ist 5c fertig, wenn dieser Test erfolgreich ist:

```text
Datei ausführbar

Script gibt keinen störenden Output aus
```
