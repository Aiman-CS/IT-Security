# Blatt 3, Aufgabe 10e: Connection-Tracking-Tabelle auslesen (Theorieaufgabe)

## Fragestellung

Suchen Sie eine Möglichkeit, den aktuellen und maximalen Füllstand sowie den Inhalt der Connection-Tracking-Tabelle auszugeben.

## 1. Aktueller Füllstand (Anzahl getrackte Verbindungen)

### Befehl

```bash
cat /proc/sys/net/netfilter/nf_conntrack_count
```

### Erklärung

- `/proc/sys/net/netfilter/nf_conntrack_count` ist eine Kernel-Variable, die die **aktuelle Anzahl** der Einträge in der Connection-Tracking-Tabelle enthält
- Der Wert ändert sich dynamisch, je nachdem wie viele Verbindungen gerade aktiv sind
- Jede neue Verbindung (TCP SYN, erstes UDP-Paket) erzeugt einen neuen Eintrag
- Beendete Verbindungen werden nach einem Timeout entfernt

### Beispiel-Ausgabe

```text
1
```

Aktuell wird 1 Verbindung getrackt.

## 2. Maximaler Füllstand (Maximum der Tabelle)

### Befehl

```bash
cat /proc/sys/net/netfilter/nf_conntrack_max
```

### Erklärung

- `/proc/sys/net/netfilter/nf_conntrack_max` enthält die **maximale Anzahl** an Einträgen, die die Tabelle aufnehmen kann
- Wenn dieses Limit erreicht wird, werden neue Verbindungen verworfen und im Kernel-Log erscheint die Meldung `nf_conntrack: table full, dropping packet`
- Der Wert kann mit `echo WERT > /proc/sys/net/netfilter/nf_conntrack_max` angepasst werden

### Beispiel-Ausgabe

```text
16384
```

Maximal können 16384 Verbindungen gleichzeitig getrackt werden.

## 3. Inhalt der Connection-Tracking-Tabelle

### Methode 1: Über das proc-Dateisystem

```bash
cat /proc/net/nf_conntrack
```

### Erklärung

- `/proc/net/nf_conntrack` enthält alle **aktuellen Einträge** der Tabelle
- Jede Zeile ist eine getrackte Verbindung
- Die Datei wird direkt vom Kernel bereitgestellt und ist immer aktuell

### Beispiel-Ausgabe

```text
ipv4     2 tcp      6 105 TIME_WAIT src=10.153.210.2 dst=10.153.210.3 sport=53410 dport=22 src=10.153.210.3 dst=10.153.210.2 sport=22 dport=53410 [ASSURED] mark=0 zone=0 use=2
```

### Aufbau einer Zeile

| Feld | Bedeutung | Beispiel |
|---|---|---|
| `ipv4` | Protokollfamilie | IPv4 |
| `2` | Layer-3-Protokollnummer | 2 = IPv4 |
| `tcp` | Transport-Protokoll | TCP |
| `6` | Layer-4-Protokollnummer | 6 = TCP |
| `105` | Verbleibende Sekunden bis Timeout | 105 Sekunden |
| `TIME_WAIT` | Verbindungsstatus | TCP-Verbindung wurde beendet |
| Erste Adressgruppe | **Originale Richtung** (Client → Server) | src=10.153.210.2 dst=10.153.210.3 sport=53410 dport=22 |
| Zweite Adressgruppe | **Antwort-Richtung** (Server → Client) | src=10.153.210.3 dst=10.153.210.2 sport=22 dport=53410 |
| `[ASSURED]` | Verbindung hat Traffic in beiden Richtungen gesehen | Eintrag wird nicht vorzeitig gelöscht |

### Methode 2: Mit dem conntrack-Tool

```bash
conntrack -L
```

### Erklärung

- `conntrack` ist ein Userspace-Tool zur Verwaltung der Connection-Tracking-Tabelle
- `-L` = Liste alle Einträge auf
- Bietet mehr Optionen als `/proc/net/nf_conntrack`, z.B. Filtern nach Protokoll oder IP

Weitere nützliche Optionen:

```bash
# Nur TCP-Verbindungen anzeigen
conntrack -L -p tcp

# Nur Verbindungen zu einer bestimmten IP
conntrack -L -d 10.153.210.3

# Statistiken anzeigen
conntrack -S
```

**Hinweis:** Das Tool `conntrack` muss ggf. erst installiert werden (`apt install conntrack`). Die `/proc`-Methode funktioniert immer ohne zusätzliche Software.

## Zusammenfassung

| Information | Befehl |
|---|---|
| Aktueller Füllstand | `cat /proc/sys/net/netfilter/nf_conntrack_count` |
| Maximaler Füllstand | `cat /proc/sys/net/netfilter/nf_conntrack_max` |
| Inhalt der Tabelle | `cat /proc/net/nf_conntrack` oder `conntrack -L` |
