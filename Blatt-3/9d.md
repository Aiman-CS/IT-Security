# Blatt 3, Aufgabe 9d: Statische IPv4-Firewall auf pcsec1

## Aufgabenstellung

Das Script soll:

- die geforderten Dienste erlauben
- Logging für bestimmte Dienste aktivieren
- Telnet nur zwischen `pcsec1` und `pcsec2` erlauben
- das Regelwerk ohne dynamisches Connection Tracking umsetzen

## Warum die Firewall statisch ist

Die Aufgabe verlangt eine statische IPv4-Firewall. Deshalb wurde kein dynamisches Connection Tracking verwendet.

Es wird also nicht mit Regeln wie dieser gearbeitet:

```bash
-m conntrack --ctstate ESTABLISHED,RELATED
```

Stattdessen werden für TCP und UDP die benötigten Richtungen explizit erlaubt.

Beispiel SSH:

```text
Client zu Server:
Zielport 22, also --dport 22

Antwort vom Server:
Quellport 22, also --sport 22
```

Dadurch ist das Regelwerk statisch, weil keine Verbindungstabelle ausgewertet wird.

## Logging

Für TCP-Protokolle soll nur der Verbindungsaufbau geloggt werden.

Dafür wurde `--syn` verwendet.

Beispiel SSH eingehend:

```bash
iptables -A INPUT -p tcp --dport 22 --syn -j LOG --log-prefix "SSH-IN-NEW: "
```

Das bedeutet:

- Es werden nur TCP-SYN-Pakete geloggt
- Ein SYN-Paket steht für den Beginn einer TCP-Verbindung
- Nicht jedes einzelne Paket der Verbindung wird geloggt

Für UDP-DNS gibt es keinen TCP-Verbindungsaufbau. Deshalb wird dort die DNS-Abfrage über Zielport 53 geloggt.

## Finale Script-Konfiguration

Das folgende Script wurde auf `pcsec1` unter `/home/secpgast/Abgaben/9/9d-firewall` abgelegt:

```bash
#!/bin/bash

IPT="/sbin/iptables"

PCSEC1_IP="10.153.210.2"
PCSEC2_IP="10.153.210.3"

# Alle vorhandenen Regeln löschen
$IPT -F
$IPT -X
$IPT -t nat -F
$IPT -t nat -X
$IPT -t mangle -F
$IPT -t mangle -X

# Default-Policies
$IPT -P INPUT DROP
$IPT -P OUTPUT DROP
$IPT -P FORWARD DROP

# Loopback erlauben
$IPT -A INPUT -i lo -j ACCEPT
$IPT -A OUTPUT -o lo -j ACCEPT

########################################
# FTP, TCP 20/21, ohne Logging
########################################

$IPT -A INPUT  -p tcp --dport 20 -j ACCEPT
$IPT -A INPUT  -p tcp --sport 20 -j ACCEPT
$IPT -A OUTPUT -p tcp --dport 20 -j ACCEPT
$IPT -A OUTPUT -p tcp --sport 20 -j ACCEPT
$IPT -A FORWARD -p tcp --dport 20 -j ACCEPT
$IPT -A FORWARD -p tcp --sport 20 -j ACCEPT

$IPT -A INPUT  -p tcp --dport 21 -j ACCEPT
$IPT -A INPUT  -p tcp --sport 21 -j ACCEPT
$IPT -A OUTPUT -p tcp --dport 21 -j ACCEPT
$IPT -A OUTPUT -p tcp --sport 21 -j ACCEPT
$IPT -A FORWARD -p tcp --dport 21 -j ACCEPT
$IPT -A FORWARD -p tcp --sport 21 -j ACCEPT

########################################
# SSH, TCP 22, mit Logging nur SYN
########################################

$IPT -A INPUT  -p tcp --dport 22 --syn -j LOG --log-prefix "SSH-IN-NEW: "
$IPT -A INPUT  -p tcp --dport 22 -j ACCEPT
$IPT -A INPUT  -p tcp --sport 22 -j ACCEPT

$IPT -A OUTPUT -p tcp --dport 22 --syn -j LOG --log-prefix "SSH-OUT-NEW: "
$IPT -A OUTPUT -p tcp --dport 22 -j ACCEPT
$IPT -A OUTPUT -p tcp --sport 22 -j ACCEPT

$IPT -A FORWARD -p tcp --dport 22 --syn -j LOG --log-prefix "SSH-FWD-NEW: "
$IPT -A FORWARD -p tcp --dport 22 -j ACCEPT
$IPT -A FORWARD -p tcp --sport 22 -j ACCEPT

########################################
# SMTP, TCP 25, mit Logging nur SYN
########################################

$IPT -A INPUT  -p tcp --dport 25 --syn -j LOG --log-prefix "SMTP-IN-NEW: "
$IPT -A INPUT  -p tcp --dport 25 -j ACCEPT
$IPT -A INPUT  -p tcp --sport 25 -j ACCEPT

$IPT -A OUTPUT -p tcp --dport 25 --syn -j LOG --log-prefix "SMTP-OUT-NEW: "
$IPT -A OUTPUT -p tcp --dport 25 -j ACCEPT
$IPT -A OUTPUT -p tcp --sport 25 -j ACCEPT

$IPT -A FORWARD -p tcp --dport 25 --syn -j LOG --log-prefix "SMTP-FWD-NEW: "
$IPT -A FORWARD -p tcp --dport 25 -j ACCEPT
$IPT -A FORWARD -p tcp --sport 25 -j ACCEPT

########################################
# DNS-Abfragen, UDP 53, mit Logging
########################################

$IPT -A INPUT  -p udp --dport 53 -j LOG --log-prefix "DNS-IN-QUERY: "
$IPT -A INPUT  -p udp --dport 53 -j ACCEPT
$IPT -A INPUT  -p udp --sport 53 -j ACCEPT

$IPT -A OUTPUT -p udp --dport 53 -j LOG --log-prefix "DNS-OUT-QUERY: "
$IPT -A OUTPUT -p udp --dport 53 -j ACCEPT
$IPT -A OUTPUT -p udp --sport 53 -j ACCEPT

$IPT -A FORWARD -p udp --dport 53 -j LOG --log-prefix "DNS-FWD-QUERY: "
$IPT -A FORWARD -p udp --dport 53 -j ACCEPT
$IPT -A FORWARD -p udp --sport 53 -j ACCEPT

########################################
# NTP-Abfragen, UDP 123, ohne Logging
########################################

$IPT -A INPUT  -p udp --dport 123 -j ACCEPT
$IPT -A INPUT  -p udp --sport 123 -j ACCEPT
$IPT -A OUTPUT -p udp --dport 123 -j ACCEPT
$IPT -A OUTPUT -p udp --sport 123 -j ACCEPT
$IPT -A FORWARD -p udp --dport 123 -j ACCEPT
$IPT -A FORWARD -p udp --sport 123 -j ACCEPT

########################################
# Telnet, TCP 23, nur pcsec1 <-> pcsec2
########################################

# pcsec1 -> pcsec2
$IPT -A OUTPUT -p tcp -s $PCSEC1_IP -d $PCSEC2_IP --dport 23 -j ACCEPT
$IPT -A INPUT  -p tcp -s $PCSEC2_IP -d $PCSEC1_IP --sport 23 -j ACCEPT

# pcsec2 -> pcsec1
$IPT -A INPUT  -p tcp -s $PCSEC2_IP -d $PCSEC1_IP --dport 23 -j ACCEPT
$IPT -A OUTPUT -p tcp -s $PCSEC1_IP -d $PCSEC2_IP --sport 23 -j ACCEPT

echo "Statische IPv4-Firewall fuer Aufgabe 9d wurde geladen."
exit 0
```
