# Blatt 3, Aufgabe 9b: Vergleich von iptables, iptables-restore und ferm

## Aufgabenstellung

In Aufgabe 9b soll bewertet werden, welche Möglichkeit für die Firewall-Konfiguration genutzt werden soll:

- direkter Aufruf von `iptables`
- Nutzung von `iptables-restore`
- Nutzung des Tools `ferm`

Dabei sollen die Vor- und Nachteile der jeweiligen Methode erklärt werden. Am Ende muss man sich für eine Methode entscheiden, die für die folgenden Aufgaben des Übungsblatts verwendet wird.

## 1. Direkter Aufruf von iptables

Beim direkten Aufruf von `iptables` werden Firewall-Regeln einzeln über die Kommandozeile oder in einem Shell-Script gesetzt.

Beispiel:

```bash
iptables -A INPUT -p tcp --dport 22 -j ACCEPT
```

## Vorteile

- Einfach zu verstehen
- Keine zusätzlichen Tools notwendig
- Regeln können Schritt für Schritt getestet werden
- Gut geeignet für kleinere Regelwerke
- Passt gut zu Shell-Scripts, wie sie in den späteren Aufgaben verlangt werden

## Nachteile

- Größere Regelwerke werden schnell unübersichtlich
- Viele einzelne Befehle können fehleranfällig sein
- Regeln werden nacheinander gesetzt
- Während das Script läuft, kann kurzzeitig ein unvollständiger Firewall-Zustand entstehen

## 2. Nutzung von iptables-restore

Mit `iptables-restore` kann ein vollständiges Regelwerk aus einer Datei geladen werden.

Beispiel:

```bash
iptables-restore < firewall.rules
```

## Vorteile

- Sehr gut für vollständige Regelwerke geeignet
- Regeln können reproduzierbar geladen werden
- Schneller als viele einzelne `iptables`-Befehle
- Das Regelwerk steht zentral in einer Datei
- Weniger Risiko, dass nur ein Teil der Regeln manuell gesetzt wird

## Nachteile

- Syntax ist weniger intuitiv als einzelne `iptables`-Befehle
- Fehler in der Datei können dazu führen, dass das Regelwerk nicht korrekt geladen wird
- Für Anfänger schwerer zu debuggen
- Einzelne Regeln lassen sich nicht so direkt Schritt für Schritt testen

## 3. Nutzung von ferm

`ferm` ist ein Tool, mit dem Firewall-Regeln strukturierter beschrieben werden können. Es erzeugt daraus iptables-Regeln.

## Vorteile

- Gute Lesbarkeit bei komplexeren Regelwerken
- Regeln können übersichtlich verschachtelt werden
- Wiederholungen lassen sich vermeiden
- Wartung großer Firewall-Konfigurationen wird einfacher

## Nachteile

- Muss zusätzlich installiert werden
- Man muss zuerst die eigene Syntax von `ferm` lernen
- Fehlersuche kann schwieriger sein, da man nicht direkt mit iptables arbeitet
- Für kleine Übungsaufgaben kann es überdimensioniert sein

## 4. Entscheidung für die weiteren Aufgaben

Für die weiteren Aufgaben dieses Übungsblatts wird der direkte Aufruf von `iptables` in einem Shell-Script verwendet.

Der Grund dafür ist, dass das geforderte Regelwerk noch überschaubar ist. Außerdem sind die einzelnen Befehle direkt nachvollziehbar und können einfach getestet werden. Da in den späteren Aufgaben ohnehin Scripts unter bestimmten Pfaden abgelegt werden müssen, passt diese Methode gut zur Aufgabenstellung.

