# Blatt 3, Aufgabe 9c: IPv4- und IPv6-Ping-Firewall auf gwsec

## Aufgabenstellung

In Aufgabe 9c soll auf dem Router `gwsec` am Interface `ens7` eine IPv4- und IPv6-Firewall eingerichtet werden.

Die Firewall soll auf `ens7` spezifisch nur ICMP Echo Request und Echo Reply erlauben, also Ping-Pakete. Danach soll die Funktionalität von `pcsec1` aus mit `ping` für IPv4 und `ping6` für IPv6 getestet werden.

Zusätzlich soll erklärt werden, worin der Unterschied zwischen IPv4 und IPv6 besteht und was nötig ist, damit Ping in beiden Fällen funktioniert.

## Ziel

Ziel war:

- Auf `gwsec` das Interface `ens7` absichern
- Für IPv4 nur ICMP Echo Request und Echo Reply erlauben
- Für IPv6 ICMPv6 Echo Request und Echo Reply erlauben
- IPv6 Neighbor Discovery berücksichtigen, damit `ping6` überhaupt funktioniert
- Von `pcsec1` aus testen
- Ergebnisse dokumentieren

## 2. IPv4-Firewall auf gwsec einrichten

Für IPv4 wurden zuerst alte Regeln gelöscht:

```bash
iptables -F
iptables -X
```

Danach wurden ICMP Echo Request und Echo Reply auf `ens7` erlaubt:

```bash
iptables -A INPUT -i ens7 -p icmp --icmp-type echo-request -j ACCEPT
iptables -A INPUT -i ens7 -p icmp --icmp-type echo-reply -j ACCEPT

iptables -A OUTPUT -o ens7 -p icmp --icmp-type echo-request -j ACCEPT
iptables -A OUTPUT -o ens7 -p icmp --icmp-type echo-reply -j ACCEPT
```

Anschließend wurde alles andere auf `ens7` verworfen:

```bash
iptables -A INPUT -i ens7 -j DROP
iptables -A OUTPUT -o ens7 -j DROP
iptables -A FORWARD -i ens7 -j DROP
iptables -A FORWARD -o ens7 -j DROP
```

## 5. Erster IPv6-Test und Fehler

Danach wurde von `pcsec1` aus IPv6 getestet:

```bash
ping6 -c 3 2001:4ca0:4001:f21::1
```

Ergebnis beim ersten Versuch:

```text
PING 2001:4ca0:4001:f21::1(2001:4ca0:4001:f21::1) 56 data bytes
From 2001:4ca0:4001:f21::2 icmp_seq=1 Destination unreachable: Address unreachable
From 2001:4ca0:4001:f21::2 icmp_seq=2 Destination unreachable: Address unreachable
From 2001:4ca0:4001:f21::2 icmp_seq=3 Destination unreachable: Address unreachable

--- 2001:4ca0:4001:f21::1 ping statistics ---
3 packets transmitted, 0 received, +3 errors, 100% packet loss, time 2046ms
```

Der IPv6-Ping hat zuerst nicht funktioniert.

Grund: Es waren nur ICMPv6 Echo Request und Echo Reply erlaubt. Bei IPv6 reicht das aber nicht immer aus, weil IPv6 für die lokale Nachbarerkennung ICMPv6 Neighbor Discovery verwendet.

## 6. Warum IPv6 anders ist

Bei IPv4 wird die lokale Adressauflösung über ARP gemacht.

ARP läuft nicht über ICMP und wird deshalb durch ICMP-Regeln in `iptables` nicht direkt blockiert.

Bei IPv6 gibt es kein ARP mehr. IPv6 verwendet stattdessen Neighbor Discovery. Neighbor Discovery läuft über ICMPv6.

Wichtige ICMPv6-Typen:

```text
128 = Echo Request
129 = Echo Reply
135 = Neighbor Solicitation
136 = Neighbor Advertisement
```

Wenn man bei IPv6 nur Echo Request und Echo Reply erlaubt, kann `ping6` trotzdem fehlschlagen, weil der Rechner die MAC-Adresse des Nachbarn nicht auflösen kann.

Deshalb mussten zusätzlich diese ICMPv6-Typen erlaubt werden:

```text
135 = Neighbor Solicitation
136 = Neighbor Advertisement
```

## 7. IPv6-Firewall auf gwsec korrigieren

Die IPv6-Regeln wurden sauber neu gesetzt:

```bash
ip6tables -F
ip6tables -X
```

Dann wurden ICMPv6 Echo Request und Echo Reply erlaubt:

```bash
ip6tables -A INPUT -i ens7 -p ipv6-icmp --icmpv6-type 128 -j ACCEPT
ip6tables -A INPUT -i ens7 -p ipv6-icmp --icmpv6-type 129 -j ACCEPT

ip6tables -A OUTPUT -o ens7 -p ipv6-icmp --icmpv6-type 128 -j ACCEPT
ip6tables -A OUTPUT -o ens7 -p ipv6-icmp --icmpv6-type 129 -j ACCEPT
```

Zusätzlich wurden Neighbor Solicitation und Neighbor Advertisement erlaubt:

```bash
ip6tables -A INPUT -i ens7 -p ipv6-icmp --icmpv6-type 135 -j ACCEPT
ip6tables -A INPUT -i ens7 -p ipv6-icmp --icmpv6-type 136 -j ACCEPT

ip6tables -A OUTPUT -o ens7 -p ipv6-icmp --icmpv6-type 135 -j ACCEPT
ip6tables -A OUTPUT -o ens7 -p ipv6-icmp --icmpv6-type 136 -j ACCEPT
```

Danach wurde alles andere auf `ens7` verworfen:

```bash
ip6tables -A INPUT -i ens7 -j DROP
ip6tables -A OUTPUT -o ens7 -j DROP
ip6tables -A FORWARD -i ens7 -j DROP
ip6tables -A FORWARD -o ens7 -j DROP
```

## 10. Kurzer Abgabetext

```text
Auf gwsec wurde auf dem Interface ens7 eine IPv4- und IPv6-Firewall eingerichtet. Für IPv4 wurden ICMP Echo Request und Echo Reply erlaubt, alle anderen Pakete auf ens7 wurden verworfen. Der Test von pcsec1 mit ping auf 10.153.210.1 war erfolgreich.

Für IPv6 wurden zunächst ebenfalls ICMPv6 Echo Request und Echo Reply erlaubt. Der erste Test mit ping6 schlug jedoch fehl, weil IPv6 Neighbor Discovery blockiert wurde. Deshalb wurden zusätzlich ICMPv6 Neighbor Solicitation und Neighbor Advertisement erlaubt. Danach war der Test von pcsec1 mit ping6 auf 2001:4ca0:4001:f21::1 erfolgreich.

Der Unterschied besteht darin, dass IPv4 für die lokale Adressauflösung ARP verwendet, während IPv6 dafür ICMPv6 Neighbor Discovery nutzt. Damit Ping in beiden Fällen funktioniert, müssen bei IPv6 neben Echo Request und Echo Reply auch die notwendigen Neighbor-Discovery-Pakete erlaubt werden.
```
