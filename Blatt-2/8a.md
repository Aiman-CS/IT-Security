# Aufgabe 8a: John the Ripper installieren, Passwortdatei herunterladen und Hash starten

## Was ist John the Ripper?

**John the Ripper** ist ein Passwort-Cracking-Tool. Es wird verwendet, um Passwort-Hashes zu testen und herauszufinden, ob ein Passwort schwach ist.

Wichtig: John entschlüsselt das Passwort nicht direkt. Stattdessen probiert John viele mögliche Passwörter aus, berechnet davon jeweils den Hash und vergleicht diesen mit dem Hash aus der Datei.

---

## Was wurde gemacht?

Auf `gwsec` wurde John the Ripper installiert. Danach wurde die Datei `passwd` von der angegebenen URL heruntergeladen und hier gespeichert:

```text
/home/secpgast/Abgaben/8/passwd
```

Die Datei enthält einen Passwort-Hash und wurde nicht verändert.

---

## Befehle

```bash
apt update
apt install -y john wget ca-certificates
mkdir -p /home/secpgast/Abgaben/8
wget -O /home/secpgast/Abgaben/8/passwd https://secp-unit.secp.lab.nm.ifi.lmu.de/static/passwd
ls -l /home/secpgast/Abgaben/8/passwd
cat /home/secpgast/Abgaben/8/passwd
john --test
john /home/secpgast/Abgaben/8/passwd
```

---

## Ergebnis des Downloads

Die Datei wurde erfolgreich heruntergeladen:

```text
/home/secpgast/Abgaben/8/passwd saved [35/35]
```

Die Datei liegt am richtigen Ort:

```text
-rw-r--r-- 1 root root 35 May  4 12:50 /home/secpgast/Abgaben/8/passwd
```

Der Inhalt der Datei ist:

```text
$1$x29iljrc$NPa4wl16VV8M.cpRAKe0Y0
```

Das ist ein Passwort-Hash. Die Datei darf nicht verändert werden.

---

## Was bedeutet der Hash?

Der Hash beginnt mit:

```text
$1$
```

Dieses Format erkennt John als **md5crypt**.

Beim Start von John wurde deshalb angezeigt:

```text
Loaded 1 password hash (md5crypt [MD5 32/64 X2])
```

Das bedeutet:

- John hat 1 Hash aus der Datei geladen.
- Der Hash-Typ wurde als `md5crypt` erkannt.
- John kann jetzt versuchen, das passende Passwort zu finden.

---

## Woher weiß John, welche Datei er cracken soll?

John sucht nicht automatisch alle Passwörter auf dem System.

Man muss John genau sagen, welche Datei er verwenden soll:

```bash
john /home/secpgast/Abgaben/8/passwd
```

Dieser Befehl bedeutet:

```text
Lies den Hash aus genau dieser Datei und versuche das passende Passwort zu finden.
```

John verwendet also nur die angegebene Datei:

```text
/home/secpgast/Abgaben/8/passwd
```

---

## Was bedeutet die aktuelle John-Ausgabe?

Beim Start wurde Folgendes angezeigt:

```text
Loaded 1 password hash (md5crypt [MD5 32/64 X2])
Press 'q' or Ctrl-C to abort, almost any other key for status
0g 0:00:00:38 3/3 0g/s 13945p/s 13945c/s 13945C/s cruisos..cruista
0g 0:00:01:04 3/3 0g/s 13964p/s 13964c/s 13964C/s joasho..joashu
```

Wichtig ist hier vor allem:

```text
0g
```

Das bedeutet:

```text
0 guesses cracked
```

Also: John hat das Passwort zu diesem Zeitpunkt noch nicht gefunden.

Die Werte wie:

```text
13945p/s
13945c/s
```

zeigen ungefähr, wie viele Passwortkandidaten pro Sekunde getestet werden.

Dass John länger läuft, ist normal. Er ist noch nicht fertig, solange kein Passwort angezeigt wird oder der Prozess nicht beendet ist.

---

## Wie erkennt man, ob John fertig ist?

Wenn John das Passwort gefunden hat, zeigt er normalerweise eine Zeile mit dem gefundenen Passwort an.

Zusätzlich kann man jederzeit prüfen, ob bereits ein Passwort gefunden wurde:

```bash
john --show /home/secpgast/Abgaben/8/passwd
```

Wenn noch nichts gefunden wurde, kommt ungefähr:

```text
0 password hashes cracked, 1 left
```

Wenn es gefunden wurde, zeigt John das Passwort an.

---

## Wie stoppt oder pausiert man John?

Während John läuft:

- Taste `q` drücken, um sauber zu beenden
- oder `Ctrl+C`, um abzubrechen

John speichert den Fortschritt normalerweise. Später kann man fortsetzen mit:

```bash
john --restore
```

---

## Wenn das Passwort wirklich 6-stellig numerisch ist

Da in der Aufgabe steht, dass es ein 6-stelliges Passwort ist, kann man gezielt alle Zahlen von `000000` bis `999999` testen.

Dafür kann man eine Wortliste erzeugen:

```bash
seq -w 000000 999999 > /tmp/6digits.txt
```

Dann John mit dieser Wortliste starten:

```bash
john --wordlist=/tmp/6digits.txt /home/secpgast/Abgaben/8/passwd
```

Danach das Ergebnis anzeigen:

```bash
john --show /home/secpgast/Abgaben/8/passwd
```

Das ist effizienter als John einfach ohne Einschränkung laufen zu lassen, weil dann genau der passende Suchraum für ein 6-stelliges numerisches Passwort geprüft wird.
