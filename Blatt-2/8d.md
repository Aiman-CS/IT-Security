# Aufgabe 8d: Wordlist generieren und Passwort mit John knacken

## Ziel der Aufgabe

In Aufgabe **8d** sollte ein Script erstellt werden, das alle möglichen Passwörter aus Aufgabe **8c** zeilenweise erzeugt.

Das Passwort-Muster aus Aufgabe 8c war:

```regex
^[a-f]{2}[A-Z][0-9][a-z]{2}$
```

Das bedeutet:

```text
1. Zeichen: Kleinbuchstabe a bis f
2. Zeichen: Kleinbuchstabe a bis f
3. Zeichen: Großbuchstabe A bis Z
4. Zeichen: Ziffer 0 bis 9
5. Zeichen: Kleinbuchstabe a bis z
6. Zeichen: Kleinbuchstabe a bis z
```

Damit gibt es insgesamt:

```text
6 * 6 * 26 * 10 * 26 * 26 = 6.327.360 mögliche Passwörter
```

Diese möglichen Passwörter wurden mit einem Script erzeugt und anschließend mit **John the Ripper** im Wordlist-Modus gegen den Hash aus der Datei `passwd` getestet.

---

## Verwendete Dateien

Die Hash-Datei liegt hier:

```text
/home/secpgast/Abgaben/8/passwd
```

Das Wordlist-Script muss hier liegen:

```text
/home/secpgast/Abgaben/8/generate_wordlist
```

Das geknackte Passwort muss hier gespeichert werden:

```text
/home/secpgast/Abgaben/8/password.txt
```

---

## Script: generate_wordlist

Das Script wurde unter folgendem Pfad erstellt:

```bash
nano /home/secpgast/Abgaben/8/generate_wordlist
```

Inhalt des Scripts:

```bash
#!/bin/bash

for a in {a..f}; do
  for b in {a..f}; do
    for c in {A..Z}; do
      for d in {0..9}; do
        for e in {a..z}; do
          for f in {a..z}; do
            echo "${a}${b}${c}${d}${e}${f}"
          done
        done
      done
    done
  done
done
```

Die erste Zeile ist die Shebang-Zeile:

```bash
#!/bin/bash
```

Sie sagt dem System, dass das Script mit Bash ausgeführt werden soll.

---

## Script ausführbar machen

Damit das Script direkt ausgeführt werden kann, wurde es ausführbar gemacht:

```bash
chmod +x /home/secpgast/Abgaben/8/generate_wordlist
```

Das ist notwendig, weil die Aufgabe ausdrücklich verlangt, dass das Script ausführbar ist.

---

## Warum das Script so aufgebaut ist

Das Script verwendet verschachtelte Schleifen.

Jede Schleife steht für eine Stelle im Passwort:

| Stelle | Schleife | Mögliche Zeichen |
|---:|---|---|
| 1 | `for a in {a..f}` | a bis f |
| 2 | `for b in {a..f}` | a bis f |
| 3 | `for c in {A..Z}` | A bis Z |
| 4 | `for d in {0..9}` | 0 bis 9 |
| 5 | `for e in {a..z}` | a bis z |
| 6 | `for f in {a..z}` | a bis z |

Für jede Kombination gibt das Script ein Passwort mit `echo` aus.

Beispielausgabe:

```text
adF4lj
adF4lk
adF4ll
adF4lm
adF4ln
adF4lo
adF4lp
```

Diese Ausgabe passt zum Muster:

```text
zwei Kleinbuchstaben, ein Großbuchstabe, eine Ziffer, zwei Kleinbuchstaben
```

Beispiel:

```text
adF4lp
```

Bedeutung:

```text
a     erster Kleinbuchstabe von a bis f
d     zweiter Kleinbuchstabe von a bis f
F     Großbuchstabe
4     Ziffer
l p   zwei Kleinbuchstaben
```

## Wordlist-Datei erzeugen

Die Ausgabe des Scripts wurde in eine Wordlist-Datei geschrieben:

```bash
/home/secpgast/Abgaben/8/generate_wordlist > /tmp/wordlist.txt
```

Dadurch stehen alle generierten Passwortkandidaten zeilenweise in:

```text
/tmp/wordlist.txt
```

Diese Datei kann John the Ripper dann im Wordlist-Modus verwenden.

---

## John im Wordlist-Modus starten

John wurde mit der erzeugten Wordlist gestartet:

```bash
john --wordlist=/tmp/wordlist.txt /home/secpgast/Abgaben/8/passwd
```

Bedeutung:

```text
john
```

startet John the Ripper.

```text
--wordlist=/tmp/wordlist.txt
```

sagt John, dass nur die Passwörter aus dieser Wordlist ausprobiert werden sollen.

```text
/home/secpgast/Abgaben/8/passwd
```

ist die Datei mit dem Hash, der geknackt werden soll.

John testet also jedes Passwort aus der Wordlist, berechnet den passenden md5crypt-Hash und vergleicht ihn mit dem Hash aus der Datei `passwd`.

---

## Passwort in password.txt speichern

Die Aufgabe verlangt, dass nur das 6-stellige Passwort in der Datei `password.txt` steht.

Dafür wurde dieser Befehl verwendet:

```bash
john --show /home/secpgast/Abgaben/8/passwd | head -n 1 | cut -d: -f2 > /home/secpgast/Abgaben/8/password.txt
```

Bedeutung:

```text
john --show /home/secpgast/Abgaben/8/passwd
```

zeigt das gefundene Passwort an.

```text
head -n 1
```

nimmt nur die erste Zeile.

```text
cut -d: -f2
```

trennt die Zeile am Doppelpunkt und nimmt nur den Passwortteil.

```text
> /home/secpgast/Abgaben/8/password.txt
```

speichert das Ergebnis in die geforderte Datei.

## Ergebnis prüfen


Ausgabe:

```text
aaZ8fp
```

Damit steht in der Datei nur das 6-stellige Passwort, wie in der Aufgabe verlangt.
